# 🔧 Вирішення мережевих проблем

## Проблема: "Network request failed"

Якщо ви отримуєте помилку "Network request failed" при реєстрації або логіні, виконайте наступні кроки:

### 1. Перевірте, чи бекенд запущений

```bash
# Перевірте, чи бекенд відповідає
curl http://localhost:3001

# Або через IP адресу
curl http://192.168.10.192:3001
```

### 2. Перевірте мережеві налаштування

```bash
# Запустіть скрипт перевірки
./check-network.sh
```

### 3. Налаштування для різних платформ

#### 📱 iOS Simulator
- Використовує `http://192.168.10.192:3001`
- Переконайтеся, що бекенд слухає на всіх інтерфейсах

#### 🤖 Android Emulator
- Використовує `http://10.0.2.2:3001`
- Це спеціальна адреса для доступу до localhost хост-машини

#### 📱 Фізичний пристрій
- Використовує `http://192.168.10.192:3001`
- Переконайтеся, що пристрій в тій же мережі

### 4. Перевірте брандмауер

```bash
# Перевірте, чи порт 3001 відкритий
lsof -i :3001
```

### 5. Альтернативні рішення

#### Варіант 1: Використання ngrok (для тестування)
```bash
# Встановіть ngrok
npm install -g ngrok

# Створіть тунель
ngrok http 3001

# Використовуйте отриману URL в API_URL
```

#### Варіант 2: Зміна порту
```bash
# В taxi_backend/.env змініть
PORT=3000

# В src/config/api.ts змініть порт
return 'http://192.168.10.192:3000';
```

### 6. Діагностика в додатку

Додаток тепер має логування. Перевірте консоль для діагностики:

```
🚀 Реєстрація пасажира: { url: 'http://192.168.10.192:3001/api/auth/register', body: {...} }
📡 Відповідь сервера: { status: 200, ok: true }
✅ Реєстрація успішна: {...}
```

### 7. Тестування API

```bash
# Тест реєстрації
./test-mobile-api.sh

# Тест через curl
curl -X POST http://192.168.10.192:3001/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email": "test@example.com", "password": "password123", "fullName": "Test User", "phoneNumber": "+380123456789", "role": "passenger"}'
```

### 8. Часті проблеми та рішення

| Проблема | Рішення |
|----------|---------|
| "Network request failed" | Перевірте IP адресу та брандмауер |
| "Connection refused" | Переконайтеся, що бекенд запущений |
| "Timeout" | Перевірте мережеве з'єднання |
| "CORS error" | Перевірте налаштування CORS на бекенді |

### 9. Корисні команди

```bash
# Перезапуск бекенду
cd taxi_backend && npm run dev

# Перезапуск фронтенду
npx expo start --clear

# Перевірка процесів
ps aux | grep node

# Очищення кешу
npx expo start --clear
```

### 10. Контакт

Якщо проблеми залишаються, перевірте:
- Логи бекенду в терміналі
- Логи фронтенду в консолі Expo
- Мережеві налаштування комп'ютера
